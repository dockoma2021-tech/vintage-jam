Підготовка файлів для GitHub

Сторінка не запитує токен GitHub. Вона перевіряє локальну чернетку, порівнює її з поточним каталогом і відкриває правильні сторінки завантаження.

Перевірка…

1. Виберіть товар

2. Контроль актуальності

Перевірка поточного products.json…

3. Файли для публікації

4. Завантаження в GitHub

  1. Завантажте готові WebP-фотографії у папку вибраного товару.
  2. Замініть файл data/products.json завантаженою версією.
  3. Вставте підготовлене повідомлення commit і підтвердьте зміни.
  4. Дочекайтеся оновлення GitHub Pages і перевірте картку товару.

Захист від помилок

Не продовжуйте, якщо контроль актуальності показує, що каталог на сайті змінився після створення локальної чернетки. Спочатку поверніться в адмін-панель, завантажте поточний каталог і повторно внесіть зміни.
