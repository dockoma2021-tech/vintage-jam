# Добавление товаров в Vintage Jam

Товары хранятся в файле `data/products.json`. Каждый товар — отдельный объект внутри общего JSON-массива.

## 1. Присвойте уникальный ID

Формат:

```text
vj-000002
vj-000003
vj-000004
```

ID нельзя повторять. Для изображений используется папка с тем же ID:

```text
images/products/vj-000002/
```

## 2. Подготовьте изображения

Рекомендуемый формат — WebP.

Названия файлов:

```text
01.webp
02.webp
03.webp
```

Главным изображением считается первое в массиве `media.images`.

## 3. Скопируйте шаблон

Используйте файл:

```text
data/product-template.json
```

Скопируйте объект из шаблона и вставьте его в массив `data/products.json` перед закрывающей квадратной скобкой. Между объектами обязательно должна быть запятая.

## 4. Допустимые значения

### publication_status

- `published` — товар виден на сайте;
- `draft` — товар скрыт.

### sale_status

- `available` — в наличии;
- `reserved` — зарезервирован;
- `sold` — продан.

### price.type

- `fixed` — фиксированная цена;
- `request` — цена по запросу.

Для цены по запросу:

```json
"price": {
  "type": "request",
  "value": null,
  "currency": "UAH"
}
```

## 5. Категории

Поле `category` должно совпадать с `id` одной из категорий в `data/categories.json`.

Основные значения:

```text
paintings
art_objects
icons
watches
knives
daggers
orders_medals
silver
coins
books
porcelain
electronics
miscellaneous
```

## 6. Видео

Если видео нет, оставьте пустую строку:

```json
"youtube": "",
"shorts": ""
```

Кнопка видео на сайте тогда не отображается.

## 7. Характеристики

В `attributes` можно оставлять только нужные поля. Пустые значения желательно удалять, чтобы они не показывались в карточке товара.

Пример:

```json
"attributes": {
  "author": {
    "uk": "Ю. М. Лука",
    "en": "Yu. M. Luka"
  },
  "year": "2007",
  "material": {
    "uk": "Олія, полотно",
    "en": "Oil on canvas"
  },
  "dimensions": "96 × 79 см"
}
```

## 8. Проверка JSON

Перед сохранением проверьте:

- все строки заключены в двойные кавычки;
- между полями стоят запятые;
- после последнего поля объекта запятой нет;
- между соседними товарами есть запятая;
- квадратные и фигурные скобки закрыты;
- ID товара и путь к изображениям совпадают.

## 9. Быстрая проверка на сайте

После публикации откройте:

```text
item.html?id=vj-000002
```

Проверьте:

1. Заголовок UA/EN.
2. Главное изображение и миниатюры.
3. Цену и статус.
4. Характеристики.
5. Кнопку связи.
6. Видеообзор, если ссылка добавлена.
