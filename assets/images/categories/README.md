# Category hero images

All category showcase images use one simple naming rule and live in this folder:

`<category-id>-category-hero.webp`

Current files:

- `paintings-category-hero.webp`
- `art_objects-category-hero.webp`
- `icons-category-hero.webp`
- `watches-category-hero.webp`
- `knives-category-hero.webp`
- `daggers-category-hero.webp`
- `orders_medals-category-hero.webp`
- `silver-category-hero.webp`
- `coins-category-hero.webp`
- `books-category-hero.webp`
- `porcelain-category-hero.webp`
- `electronics-category-hero.webp`
- `miscellaneous-category-hero.webp`

To change a category image, replace the corresponding WebP file while keeping the same filename. No JavaScript or catalog product data needs to be edited.

Recommended source format: 16:9, ideally 1600x900 or 1120x630. The site displays all category hero images in the same frame size.

`category-placeholder.webp` is used only if a category image is missing or cannot be loaded.

Important: category hero images are independent from product photos. The showcase renderer does not build category imagery from product media.
